# Salesforce Automation Framework

## Project Overview

This project demonstrates web test automation for selected Salesforce CRM workflows using Selenium WebDriver and Java.

The framework is organized to support reusable automation actions and maintainable test code.

## Technologies Used

- Java
- Selenium WebDriver
- Git and GitHub

## Test Scenarios

The project covers selected CRM workflows involving:

- Accounts
- Opportunities
- Contacts
- Tasks

## Project Structure

The project uses a Maven project configuration (`pom.xml`) and Java test source files.

```text
SalesforceAutomation/
├── pom.xml
└── src/
    └── test/
        └── java/
```

## Prerequisites

- Java Development Kit (JDK)
- Apache Maven
- A compatible web browser
- Appropriate browser driver configuration, if required by the project

## How to Get Started

1. Clone or download this repository.
2. Open the project in an IDE such as Eclipse or IntelliJ IDEA.
3. Allow Maven to resolve the dependencies defined in `pom.xml`.
4. Review the Java test files and the existing test configuration.
5. Configure any required browser or Salesforce test environment settings.
6. Execute the tests according to the project's existing configuration.

## Purpose

This project was created to practise Selenium-based test automation, Java programming, and reusable automation methods.
